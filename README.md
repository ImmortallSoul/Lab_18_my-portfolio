# React Mini-Portfolio (Lab 18)

## Опис
SPA-портфоліо, розроблене на React. Проєкт містить маршрутизацію, роботу зі станом, запити до відкритого API погоди та підтримку темної теми.

## Функціонал
* **React Router Dom:** маршрутизація між сторінками `/about`, `/my-city`, `/my-future`.
* **Axios & API:** отримання поточної погоди для міста.
* **React Hooks:** використання `useState` та `useEffect`.
* **Додатково (⭐):** збереження обраної теми (світла/темна) у `localStorage`, використання іконок `react-icons`.

## Запуск проєкту
1. `npm install`
2. `npm start`
